Problem Statement & Motivation

The secondary smartphone market suffers from severe information asymmetry. Unlike new devices with fixed Manufacturer Suggested Retail Prices (MSRP), used phone transactions depend on intricate hardware wear, battery degradation, release velocity, and subjective cosmetic assessments.

Buyers often risk overpaying for depleted batteries or obsolete memory configurations, while individual sellers lack transparent pricing intelligence. PhoneValue AI eliminates this guesswork by fitting non-linear machine learning ensembles against 1,500 benchmarked secondary listings, providing empirical valuation confidence intervals.

Dataset Specifications

The reference dataset encompasses 1,500 verified device profiles spanning 5 leading international manufacturers across varying age and physical conditions.

Variable Type Domain / Range Description
brand Categorical Apple, Samsung, OnePlus, Google, Xiaomi Device manufacturer
age_months Integer 1 to 60 Months Elapsed lifespan since original launch
ram_gb Integer 4, 6, 8, 12 GB Installed system memory
storage_gb Integer 64, 128, 256 GB Internal flash storage capacity
battery_health Integer 50% to 100% Maximum remaining battery charge percentage
condition Categorical Excellent, Good, Fair, Poor Cosmetic and chassis wear rating
original_price Float ₹20,000 to ₹100,000+ Original retail purchase price in INR
resale_price Float (Target) Continuous Market valuation at transaction time

Feature Engineering & Transformation

Raw specifications were enriched with domain-specific economic metrics to improve model convergence and signal detection:

Price Per Storage Unit (₹/GB)

Computed as original_price / storage_gb to isolate premium tier pricing distinct from pure storage additions.

Age in Years

Calculated as age_months / 12.0 to align with annual product refresh cycles and consumer upgrade cadence.

Label Encoding

Serialized LabelEncoder artifacts map nominal manufacturer and condition classifications into discrete numerical spaces.

Feature Standardisation

Applied StandardScaler to ensure numerical attributes share zero-mean unit-variance distribution across estimators.

Regression Model Comparison

Three standard regression algorithms were trained and cross-validated on an 80/20 train-test partition using identical seed randomization.

Algorithm R² Score MAE (₹) RMSE (₹) Verdict
Linear Regression 0.684 ₹7,450 ₹9,120 Underfitting Baseline cannot capture exponential year-one decay.
Decision Tree Regressor 0.742 ₹5,890 ₹7,650 High Variance Sensitive to split boundaries in edge cases.
Random Forest Regressor 0.852 ₹4,120 ₹5,410 Production Champion Superior ensemble variance reduction and R².

Why Random Forest Won: Depreciation does not decay linearly. A device loses ~30-40% of value in its first 12 months, followed by a stabilizing asymptotic curve. The Random Forest Regressor excels at capturing these non-linear thresholds through ensemble bagging.

Full-Stack Implementation

The production system separates model serialization from inference through a decoupled Flask microservice:

Flask Server

Hosts REST prediction endpoints, validates schemas, and serves server-rendered templates.

Joblib Serializers

Persistent .pkl artifacts store encoders, scalers, and trained tree estimators for sub-millisecond inference.

Clean UI System

Modern dark/light CSS tokens, responsive drawer navigation, and accessible dialogs without external UI framework bloat.
