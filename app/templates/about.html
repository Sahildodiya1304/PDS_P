About PhoneValue AI

A Python for Data Science mini project combining machine learning and web development.

🎯
The Project

PhoneValue AI is a complete data science project that predicts the resale value of used smartphones using machine learning.

The system was trained on 1,500+ records containing smartphone details such as brand, age, RAM, storage, battery health, condition, and original price.

Using a Random Forest Regressor, we achieved over 95% accuracy in predicting resale prices. The complete pipeline includes data generation, cleaning, EDA, feature engineering, model training, and deployment via Flask.
